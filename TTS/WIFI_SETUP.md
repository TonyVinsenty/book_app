# Silero eugene через домашний Wi-Fi

## На компьютере

Сервер уже запущен на `http://192.168.0.106:8765`. Проверка с ПК:

```powershell
Invoke-RestMethod http://192.168.0.106:8765/health
```

Ключ доступа находится в `E:\AI\TTS\server-token.txt`. Сервер работает только на Wi-Fi адресе ПК. Если адрес ПК поменяется, узнайте новый через `ipconfig` и перезапустите сервер:

```powershell
Stop-Process -Id (Get-Content E:\AI\TTS\server.pid)
cd E:\AI\TTS
.\.venv\Scripts\python.exe D:\Projects\Codex\ReadingAPP\tool\silero_server.py --host НОВЫЙ_IP_ПК --port 8765
```

Windows не позволила автоматически добавить правило брандмауэра. Если телефон не подключается, откройте PowerShell **от имени администратора** и выполните:

```powershell
New-NetFirewallRule -DisplayName 'Verso Silero TTS (LAN)' -Direction Inbound -Action Allow -Protocol TCP -LocalAddress 192.168.0.106 -LocalPort 8765 -RemoteAddress LocalSubnet -Profile Private
```

При смене IP удалите прежнее правило и создайте новое с актуальным адресом. Не открывайте этот порт в роутере для доступа из интернета.

## На телефоне

1. Установите `verso-silero-wifi-arm64-release.apk` из этой папки. Если телефон не поддерживает ARM64, используйте `verso-silero-wifi-universal-release.apk`.
2. Подключите телефон к той же домашней сети Wi-Fi (не к гостевой).
3. Откройте книгу, коснитесь центра страницы, нажмите значок наушников в верхней панели.
4. Введите адрес `http://192.168.0.106:8765` и ключ из `E:\AI\TTS\server-token.txt`.
5. Нажмите «Слушать». При повторном запуске озвучка продолжится с сохранённого предложения. Для точного старта удерживайте слово и выберите «Озвучка». Панель можно закрыть. Пауза, продолжение и остановка доступны на странице и в системном управлении звуком, в том числе при заблокированном экране. В панели стрелки возвращают к предыдущему предложению или абзацу, кнопки − и + меняют скорость на 10% в пределах 70–130%. Ручное перелистывание не меняет место озвучки. Чтобы начать с видимой страницы, откройте панель и нажмите «Слушать с этой страницы».

Передача текста и ключа идёт по обычному HTTP внутри домашней сети. Это тестовая схема для одного пользователя.

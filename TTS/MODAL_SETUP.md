# Пробный облачный сервер озвучки

Сервер Silero развёрнут в Modal как `verso-silero`. Адрес для Verso:

`https://tvinsenty--verso-silero-serve.us-east.modal.run`

Ключ доступа хранится только на этом компьютере в `.dart_tool/modal-tts-token.txt`.
Откройте файл и скопируйте его содержимое в поле «Ключ доступа» в приложении.
Не добавляйте ключ в репозиторий и не передавайте его вместе с APK.

Установите новую сборку Verso, откройте книгу → панель озвучки →
«Подключение», введите адрес и ключ, затем нажмите «Слушать».
Облачная озвучка требует интернета. При первом запросе после простоя
контейнер запускается заново, поэтому ответ может занять несколько секунд.

Развёртывание: `modal deploy tool/modal_silero.py` из корня проекта с
авторизованным Modal CLI. Модель и manifest берутся из локальной установки
Silero, пути можно изменить переменными `VERSO_SILERO_MODEL_FILE` и
`VERSO_SILERO_MANIFEST_FILE`. Для остановки: `modal app stop verso-silero`.
После смены ключа его нужно заново развернуть и обновить в приложении.

Конфигурация: 1 CPU, 2 ГиБ RAM, 0 контейнеров в простое, максимум 1
контейнер, остановка через 60 секунд после запросов. Состояние контейнеров
не хранит книги и прогресс; приложение отправляет текст только для озвучки.

Проверка 2026-11-15: запрос без ключа → HTTP 401 (~9,8 с холодного запуска);
с ключом → HTTP 200 и WAV 48 кГц, моно, 2,54 с звука (~2,3 с после запуска).
После простоя запрос на 12,19 с звука завершился за 12,24 с вместе с запуском.
Проверка на телефоне и расходы за месяц ещё впереди.

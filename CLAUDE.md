# ReadingAPP — читалка со скорочтением (Flutter, Android + iOS)

Читалка любых книг, где в любой момент можно переключиться в скорочтение (RSVP: одно слово с выделенной буквой в одной точке; ведущая подсветка). Рабочее имя — BookApp (репозиторий `book_app`), видимое название ещё не выбрано. Функции, интерфейс, этапы и «где остановились» — в **`docs/ROADMAP.md`** (читать в начале каждой сессии, обновлять после каждого сделанного пункта). Решения по устройству — `docs/decisions/` (ADR).

## Режим работы: экономия токенов (главное правило)
- Отвечать коротко; не перечитывать то, что уже есть в контексте; читать файлы частями.
- Агентов звать на целые этапы, не на мелочи; агенту давать готовый контекст (пути, решения), чтобы он не изучал проект заново.
- В конце каждого ответа с заметной работой — одна строка «Контекст: ~N тыс. токенов».
- **Явно напоминать владельцу сменить сессию** («Пора начать новую сессию»), когда: закрыт этап или крупный пункт; контекст больше ~120 тыс. токенов; было 2+ тяжёлых запуска агентов; начинается работа над другой частью приложения. Перед этим — обновить «Где остановились» в ROADMAP и закоммитить.

## Как работать
- Владелец не программист: объяснять просто, по-русски, без техники; спрашивать только о важных решениях или когда нужен тест на устройстве. Код, идентификаторы, коммиты — на английском.
- Коммиты делать самому (каждый пункт — отдельный коммит, автор `TonyVinsenty <tvinsenty@gmail.com>`); **push — только по просьбе владельца**. Репозиторий: https://github.com/TonyVinsenty/book_app
- Основной телефон владельца — iPhone (без Mac: облачная сборка + Sideloadly, как в MoneyAPP — `D:/Projects/Claude/MoneyAPP/docs/how-to-iphone.md`); Android — эмулятор `Pixel_8`. Нативный код iOS держать минимальным: проверить его можно только облачной сборкой.
- Тексты интерфейса — только в ARB (пока только русский, всё переводимо); на «вы», гендерно-нейтрально.
- Проект не зависит от MoneyAPP/SmokingAPP; оттуда берём только опыт (сборка, подпись, CI).

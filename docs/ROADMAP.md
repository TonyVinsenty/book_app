# ROADMAP

## Цель
Хорошая читалка для себя и друзей, с перспективой выхода на рынок. Отличие от конкурентов (Stage Reader, Wordex, RSVP Reader, Ledor и др. — сделаны «скорочиталками», в основном iOS/EPUB): **полноценная читалка + бесшовный переход в скорочтение на том же слове**, качественный русский язык и FB2, Android и iOS, приятный пастельный стиль, «быстро без потери понимания».

## Принятые решения (2026-10-19)
- Стек как в прошлых проектах: Flutter, всё на телефоне, без регистрации и сервера (детали — ADR после этапа «Архитектура»).
- Методы v1: RSVP по одному слову, RSVP по фразам (2–3 слова), ведущая подсветка на обычной странице.
- Интерфейс: только русский, но всё переводимо (английский — перед выходом на рынок).
- Основной телефон для проверки — iPhone; Android — эмулятор.
- Команда: architect (Opus), разработчик (основная сессия), tester и designer (Sonnet).
- Владелец согласен со всеми рекомендациями архитектора: настоящие страницы (сначала без анимаций листания, оформление позже), папки на iPhone — оба варианта в этапе 11, картинки и сноски — этап 12, свой код вместо пакетов для выбора файлов / «Открыть в» / кодировок / «экран не гаснет», выравнивание по умолчанию влево, план этапов 5–14.
- Стиль ([макеты](design/concepts.html), https://claude.ai/artifact/BThhpZeZpLox53ZcFSU4t4): в приложение сразу идут **все 4 палитры** (Бумага, Шалфей, Лаванда, Дымка) с ночными вариантами и **все 4 шрифта книги** (Literata, PT Serif, Lora, Noto Serif); интерфейс — Manrope. Цвета — из `docs/design/concepts.html`.
- Монетизация: основное — бесплатно; платная версия — дополнительные режимы скорочтения, тренировочный полигон, подробная статистика (детали — раздел «Монетизация»).

## Интерфейс (видение владельца)
**Основной режим — только книга, никаких кнопок** (обычный текст или скорочтение).

**Тап по экрану → появляется интерфейс:**
- Слева сверху — «Библиотека»: список книг, добавление файлов и папок с телефона, свои списки (подборки) книг.
- Справа сверху — оглавление.
- Снизу: ползунок прогресса по книге, «стр. N / M», название главы, кнопки шрифта A− / A+, настройки (шрифты, стиль, всё остальное), кнопка режимов скорочтения, короткая статистика (средняя скорость, сколько осталось читать при этой скорости).

**Запуск скорочтения:** долгое нажатие на слово → с этого слова; или кнопкой → с первого слова на странице.

**В скорочтении** (элементы управления — аккуратно, не перегружая):
- пауза, перемотка назад, увеличение/уменьшение скорости, возврат к обычному тексту;
- при возврате последнее слово из скорочтения на секунду подсвечивается в обычном тексте;
- на паузе вокруг слова «проступает» текст до него — можно глазами вернуться назад, не выходя из режима;
- конец главы: автоматическая пауза, «Новая глава» с видом страницы, продолжение кнопкой «Старт».

## Функции
### Версия 1 — «читаю сам каждый день»
- Библиотека: добавление файлов (выбор, «Поделиться / Открыть в» из Файлов, Telegram, почты, Safari), папки, подборки; обложка/название/автор из файла; % прочитанного; «Продолжить»; сортировка, удаление.
- Форматы: EPUB, FB2, FB2.ZIP, TXT (автоопределение кодировки, в т. ч. Windows-1251).
- Обычное чтение: шрифт, размер, интервал, поля; пастельные темы + ночная; оглавление; прогресс по главе и книге; место запоминается до слова.
- Скорочтение: RSVP (слово / фраза), выделенная буква на месте + метки для глаз, 100–1000+ слов/мин, умный темп (паузы на знаках препинания, длинных словах, начале абзаца; плавный разгон), всё из раздела «Интерфейс»; ведущая подсветка; экран не гаснет.
- Статистика: время, слова, средняя скорость по дням и режимам.

### Версия 2 — «удобно и для других»
Закладки и цитаты, поиск по книге; DOCX, PDF (с текстом), MOBI, статьи из браузера; тренажёр и график роста скорости; опорные буквы; озвучка с подсветкой; перевод/значение слова по нажатию.

### Перед выходом на рынок
Английский интерфейс, синхронизация между устройствами, решение о платной части, легальный каталог бесплатных книг; проверить вопрос патентов Spritz.

## Монетизация (черновик, решение — перед выходом на рынок)
- Бесплатно: читалка, все форматы, RSVP по слову с умным темпом, пауза с контекстом, темы и шрифты.
- Платно («Pro»): RSVP по фразам, ведущая подсветка и будущие режимы (опорные буквы, озвучка, просмотр); тренировочный полигон (таблицы Шульте, тест скорости с вопросами на понимание, программа роста скорости); подробная статистика и цели. Возможно — синхронизация.
- Цены у конкурентов: ~$5/мес или ~$30/год. Для России — подписка + разовая покупка «навсегда».
- Ограничения из России (проверено 2026-10-19): Google Play не платит на российские счета с 12.2024; App Store — нет выплат на российские реквизиты с 2023, у пользователей из РФ почти нет способа оплаты; RuStore — платежи только для ИП/юрлиц (самозанятым отключили с 02.2026). Рабочие пути: ИП → RuStore; иностранная компания → App Store / Google Play; Boosty — поддержка (на iOS открывать платные функции через внешнюю оплату нельзя).
- В коде заранее заложить флаг «Pro» (отдельные функции включаются одной проверкой), чтобы платную часть можно было включить без переделок.

## Этап 6 — шаги (предложено 2026-10-19)
Каждый шаг — отдельный коммит; новых пакетов нет (экран не гаснет — своим кодом, ADR 0004 «Изменения»). Перед 6.2–6.6 — открыть ADR 0004 (п. 4, 7–9 и «Изменения»).
- [x] 6.1 Последняя книга при запуске (2026-10-19): `BookRepository.lastOpened()`; `main` до `runApp` спрашивает базу и передаёт `BookApp(reopenBookId:)`, стек «библиотека → читалка» строится через `onGenerateInitialRoutes` (без `home`: с ним Flutter не разрешает). Не открылась при запуске — снэкбар «Не удалось открыть последнюю книгу» и библиотека; открыта вручную — ошибка с кнопкой «К библиотеке». У `openedBookProvider` выключен автоповтор Riverpod 3 (`retry: null`): раньше битая книга ~10 раз перечитывалась с паузами, и ошибка не показывалась.

# Как поставить BookApp на iPhone с компьютера Windows

Mac не нужен: приложение собирается в облаке (GitHub Actions), а на iPhone его ставит программа
**Sideloadly** с вашим обычным Apple ID. Компьютер уже подготовлен для Zuno (iTunes, Sideloadly),
поэтому здесь только то, что отличается. Подробная инструкция с картинками ситуаций —
`D:/Projects/Claude/MoneyAPP/docs/how-to-iphone.md` (разделы 1–2, 5, 8 подходят без изменений).

## Чем BookApp отличается от Zuno
- Внутреннее имя для iOS (bundle id): **`com.tonyvinsenty.bookapp`**. Его нельзя менять в
  Sideloadly (Advanced Options не трогать) — иначе iPhone посчитает сборку другим приложением,
  и книги с прогрессом потеряются.
- Файл сборки называется `BookApp-<версия>-<номер>.ipa`.
- Бесплатная подпись: одновременно не больше **3 приложений** на один Apple ID (Zuno + BookApp —
  это два) и не больше **10 App ID за 7 дней**.

## Как получить свежую сборку
1. Откройте https://github.com/TonyVinsenty/book_app → вкладка **Actions** → слева
   **iOS build**.
2. Справа **Run workflow** → ветка **main** → зелёная кнопка **Run workflow**.
3. Через 15–25 минут у запуска появится зелёная галочка. Откройте запуск, внизу в разделе
   **Artifacts** скачайте `BookApp-….ipa`.
   - Красный крестик — сборка не прошла. Ничего не ставьте, напишите ассистенту.

## Как поставить
1. Подключите iPhone кабелем (или по Wi-Fi, если синхронизация уже включена), откройте Sideloadly.
2. Перетащите `.ipa` в окно Sideloadly, проверьте Apple ID (тот же, что всегда), **Start**.
3. Первый раз: на iPhone «Настройки» → «Основные» → «VPN и управление устройством» → ваш
   Apple ID → «Доверять». Если включён «Режим разработчика» — он уже включён для Zuno.
4. Обновление ставится так же поверх — книги и место чтения сохраняются, пока bundle id и Apple ID
   те же.

Подпись действует 7 дней; Sideloadly продлевает её сам, если компьютер включён и iPhone в той же
сети (как у Zuno).

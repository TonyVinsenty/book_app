# Как создать ключ подписи для Android (делаете вы сами)

Ключ — это файл, которым подписывается установочный файл APK. Android ставит обновление поверх
старой версии **только если оно подписано тем же ключом**. Поэтому ключ создаётся один раз и
хранится бережно. Ассистент (Claude Code) этот файл и пароли не создаёт и не видит — всё ниже вы
делаете сами в окне PowerShell.

У Zuno уже есть папка `D:\Android\keys\`. Для BookApp делаем **отдельный** ключ в той же папке.

## Шаг 1. Создать ключ
Откройте PowerShell и выполните (одной командой, можно скопировать целиком):

```powershell
& "D:\Program Files\Android\Android Studio\jbr\bin\keytool.exe" -genkeypair -v -storetype JKS `
    -keystore D:\Android\keys\bookapp-release.jks -alias bookapp -keyalg RSA -keysize 2048 -validity 10000
```

Программа спросит:
1. **Пароль хранилища** — придумайте надёжный, введите дважды (символы при вводе не видны — это
   нормально).
2. Имя, организацию, город и т. д. — можно ответить как угодно (например, имя и `RU`), на работу
   не влияет. В конце напишите `yes`.
3. Если спросит **пароль ключа** — нажмите Enter (будет тот же, что у хранилища).

Должно появиться: `[Storing D:\Android\keys\bookapp-release.jks]`.

## Шаг 2. Записать пароли в файл рядом с ключом
Создайте в Блокноте файл `D:\Android\keys\bookapp-keystore.properties` с четырьмя строками
(слэши — прямые `/`, это важно):

```properties
storeFile=D:/Android/keys/bookapp-release.jks
storePassword=ваш_пароль
keyAlias=bookapp
keyPassword=ваш_пароль
```

При сохранении в Блокноте выберите «Тип файла: Все файлы», чтобы не получилось
`.properties.txt`.

## Шаг 3. Сказать сборке, где лежит файл
В PowerShell:

```powershell
[Environment]::SetEnvironmentVariable('BOOKAPP_KEYSTORE_PROPERTIES', 'D:\Android\keys\bookapp-keystore.properties', 'User')
```

Потом **закройте и заново откройте** VS Code и все окна PowerShell — иначе они не увидят
настройку.

## Шаг 4. Проверить
В новом окне PowerShell:

```powershell
echo $env:BOOKAPP_KEYSTORE_PROPERTIES
```

Должен напечататься путь к файлу из шага 2. После этого скажите ассистенту «ключ готов» — он
соберёт первый релизный APK и проверит, что он подписан именно вашим ключом.

## Шаг 5. Резервные копии — обязательно
**Если ключ или пароль потеряются, обновить приложение у друзей будет нельзя** — только удалить
и поставить заново (книги и прогресс пропадут). Поэтому сразу:
- скопируйте `bookapp-release.jks` и `bookapp-keystore.properties` **в два места**: например, на
  флешку и в личное облако (лучше в архив с паролем);
- пароль запишите в менеджер паролей.

Никогда не кладите эти файлы в папку проекта `D:\Projects\Claude\ReadingAPP` и не отправляйте их
в чаты.

# Замеры скорости (шаг 15.1)

Дата: 2026-10-23. Версия 0.1.0+18. Цель: найти то, что человек заметит как медленное, — действие дольше 0,3 с или рывки кадров (кадр дольше 16 мс подряд).

## Коротко

- **Приложение быстрое.** Листание, прокрутка, смена шрифта, запуск скорочтения, библиотека на 200 книг — без рывков. Самые большие книги открываются быстро, кроме одной: Гиббон (1,6 млн слов) открывается 1,2 с.
- **Главная находка — запуск приложения:** около 0,6 из 0,7 с до первого кадра уходит на подготовку правил переносов слов. Это можно убрать.
- Остальное — мелочи: рывок в 35 мс на стыке глав в вертикальной прокрутке, лишние пересчёты вёрстки при смене шрифта, долгий фоновый подсчёт страниц у огромных книг (10 с у Гиббона, но он идёт в фоне и ничего не тормозит).

## Узкие места (от худшего к лучшему)

1. **Запуск: правила переносов (около 0,6 с из 0,7 с до первого кадра).** Приложение ждёт, пока разберутся правила переносов для русского и английского, и только потом показывает первый кадр. Остальная подготовка (база, настройки) занимает 0,1 с. Хватит читать готовые правила, а не разбирать текстовый файл каждый раз.
2. **Открытие огромной книги (Гиббон) — 1,2 с.** Книга сначала распаковывается, потом отдаётся в другой поток слов-разборщику целиком (копия всей книги, 9,5 млн букв), потом разбивается на 1,58 млн слов. Книг такого размера мало, но на телефоне будет дольше эмулятора.
3. **Подсчёт страниц всей книги у огромных книг — 10 с у Гиббона** (у обычных 1–3 с). Идёт в фоне, пока число страниц показано приблизительно («≈»). Пользователь это не замечает, но на слабом телефоне может затянуться.
4. **Стык глав в вертикальной прокрутке — рывок 35 мс.** Новая глава раскладывается прямо внутри кадра. На слабом телефоне рывок станет заметен (>50 мс).
5. **Смена размера шрифта — 6 пересчётов вёрстки за одно нажатие** вместо одного (по 11–50 мс каждый), один кадр доходит до 54 мс.
6. **Импорт Гиббона — 3,1 с** (идёт в фоне, показан прогресс, рывков нет). Из них около 2 с — разбор сносок и текста.
7. **Фоновая очистка при запуске** (`removeLostFiles`): 125–190 мс в фоне при 200 книгах. Не мешает.

## Что не проверено

- Реальный iPhone: числа ниже — Android-эмулятор на быстром ПК, разбор книг на телефоне может быть в 2–4 раза медленнее.
- Библиотека на 200 книг с настоящими обложками: у тестовых книг обложек нет, показаны заглушки. Нагрузку на память от 200 картинок надо смотреть отдельно.
- Отрисовка (raster) на эмуляторе нерепрезентативна, поэтому по ней выводы не делались.
- Рывки в момент, когда фоновый подсчёт страниц идёт одновременно с быстрым листанием, проверены не доказательно: адб-смахивания были медленнее подсчёта у большинства книг.
- Память: Гиббон открытым — около 214 МБ (PSS). Ошибок памяти и исключений приложения в журнале нет.

## Как мерили (для разработчика)

**Среда.** Эмулятор Pixel_8, Android 17, x86_64; сборка `flutter build apk --profile --target-platform android-x64` (профильная сборка на эмуляторе работает). Windows 11. Книги: `D:/Projects/Claude/test-books/`, `.../hard/`, `D:/Projects/Claude/test-books-200/` (200 файлов, 2,4 МБ, обложек нет).

**Метод.** Во временной сборке были добавлены строки `print` с `Stopwatch` (читали из `adb logcat -s flutter`) и счётчик кадров через `SchedulerBinding.addTimingsCallback` (раз в секунду: число кадров, кадры сборки >16 мс, растра >16 мс, худший кадр; плюс «остановка потока» — максимальный разрыв между тиками 5-мс таймера). Управление: `adb shell input tap/swipe`, поиск кнопок через `uiautomator dump`. Файлы клались в `/sdcard/Android/data/com.tonyvinsenty.bookapp/files/`, импорт запускался временным командным файлом. Вся временная правка (включая файл `lib/perf_tmp.dart`) удалена; `git status` по `lib/` чистый. `gfxinfo` для Flutter не использовался: он не видит кадры Flutter.

**Чистый Dart на Windows** (`dart --packages=.dart_tool/package_config.json`, скрипты в scratchpad): разбор + токенизация, мс — Остин 403, Диккенс 159, Достоевский 158, Гиббон 2054 (токенизация отдельно 695), Дон Кихот 514. Сохранение модели (JSON+gzip) Гиббон 466 мс, чтение 214 мс; `SmartPace` (расчёт пауз скорочтения) на главу — 4–6 мс, то есть старт скорочтения на узкие места не влияет. Размер сохранённой модели Гиббона — 4,8 МБ.

# Трудные книги этапа 12 — что должно получиться

Набор для картинок и сносок (ADR 0008). Маленькие файлы делают скрипты `tool/fixtures/make_fb2_fixtures.py` и `make_epub_fixtures.py` (общие картинки — `fixture_images.py`), лежат в `test/fixtures/fb2/` и `test/fixtures/epub/`. Снимки `.json` FB2 есть (12.4), EPUB с картинками — (12.5); со сносками — появятся в 12.6. Общее правило: **ни один файл не роняет разбор, текст не теряется, лишних пустых мест нет.**

## FB2 (`test/fixtures/fb2/`)

**`images_basic.fb2`** — картинки JPEG, PNG, GIF; `binary` и до, и после текста; обложка (`coverpage`); одна картинка использована дважды; распорка 1×1.
- Обложка — первый блок первой главы, первая страница книги.
- Картинки на местах между абзацами; повторная картинка — один файл на диске, два блока.
- Распорка 1×1 (обе стороны < 16 пикс) пропущена, виньетка GIF 40×30 показана в натуральном размере, по центру.
- В листании страница «только картинка» допустима; слов в ней нет.

**`images_broken.fb2`** — всё, что показать нельзя.
- Битый base64, обрезанный base64, пустой `binary`, `binary` с текстом вместо картинки, `image` без `binary`, `image` без адреса и с нелокальным адресом — блоки не создаются, текст вокруг цел.
- PNG «20000×20000» и JPEG «12000×9000» (> 50 Мпикс) — пропущены, приложение не падает и не тратит память.
- Два `binary` с одним id — берётся первый, без падения.
- Обложка указывает на несуществующий `binary` — книга открывается без обложки-страницы.
- Хорошая картинка `ok.png` показана.

**`notes_basic.fb2`** — сноски в `<body name="notes">` и `name="comments"`.
- Метки `[1]`, `2`, `*`, пустая, `{1}` → в тексте `1`, `2`, `*`, `*`, `1` надстрочными, акцентным цветом; тап открывает сноску.
- Сноска с двумя абзацами и заголовком — короткая, открывается в нижней панели; метка без заголовка у сноски — сноска всё равно открывается.
- `#nowhere` и ссылка без адреса — метка остаётся, серая, неактивная.
- Ссылка без `type="note"` на тело `notes` — тоже метка.
- Ссылка наружу (`https://`) — не сноска.
- `n5` ↔ `n6` ссылаются друг на друга: из панели — в той же панели со стрелкой «назад», без зацикливания и без падения.
- `n7` (на неё никто не ссылается) — не видна нигде; сноски не входят в оглавление, проценты и подсчёт слов.

**`notes_many.fb2`** — 300 сносок (как научное издание). Разбор быстрый; метки во всех абзацах; сноски «Смотри ещё» — вложенные.

## EPUB (`test/fixtures/epub/`)

**`epub_images.epub`**
- Обложка (`cover.xhtml`, обёртка `<svg><image>`, `linear` по умолчанию) — первая страница книги; страница `plate.xhtml` (только `<img>`) приклеена к главе 1 как первый блок, отдельной главы нет.
- `<img>` посреди абзаца режет его на «до», картинку и «после»; картинка в конце и в начале абзаца; одинокий `<img>`; подпись под рисунком — обычный абзац.
- GIF 40×30 — натуральный размер; повторная картинка — один файл.
- Обёртка `<svg><image>` в главе 2 — обычная картинка; **чистый SVG-рисунок пропущен** (без пустого места).
- Битая картинка (`broken.png`), `nothere.png` (нет в архиве), `huge.png`/`huge.jpg` (огромные), внешний `https://`, `<img>` без `src`, `data:` — пропущены, текст цел; битая картинка из книги, уже принятая как блок, — рамка со значком.
- Спейсер 1×1 — пропущен.
- `endpage.xhtml` в конце книги (только картинка) — приклеена к последней главе с текстом, главы без слов нет.
- Оглавление: «Глава 1», «Глава 2»; обложка и картинки в него не попадают.

**`epub_images_only.epub`** (EPUB 2, комикс/альбом) — почти нет текста: каждая картинка — страница; файлы без слов приклеены к следующей главе с текстом (последний `a3` — к предыдущей); глава без слов не создаётся; обложка (`cover.xhtml`) — первая страница; книга открывается и листается.

**`epub_notes_aside.epub`** — сноски в самой главе.
- `epub:type="noteref"`, `role="doc-noteref"`, метка `*`, `[7]` → метки в тексте; `<aside epub:type="footnote|endnote">` — тексты сносок, в потоке чтения их нет.
- Обратные ссылки «↩» и «↩︎» из текста сносок убраны; «3)» в начале endnote — не убирается (это текст), если не является обратной ссылкой.
- `fn2` ↔ `fn4` — сноска в сноске, без зацикливания.
- `#nope` и `gone.xhtml#x` — метки серые, неактивные.
- Метка из главы 2 на сноску в главе 1 (`ch1.xhtml#fn1`) — работает.

**`epub_notes_files.epub`** — сноски в отдельных файлах.
- `notes.xhtml` (в spine) — остаётся в потоке чтения как раздел «Примечания» (как сейчас), а метки в тексте всё равно открывают сноски; обратные ссылки (`1)`, `↩`, `[7]` на метку) в тексте сноски убраны.
- `hidden_notes.xhtml` (только в manifest, не в spine): цели `<p>`, `<dd>`, `<div>` (два абзаца), `<li>` — каждая находится по якорю, берётся ближайший блочный элемент; в потоке чтения скрытого файла нет.
- Сноска `n3` ссылается на `h1` — вложенная.
- Цель без элемента (`#missing`) и файл, которого нет (`text/zzz.xhtml`) — серые метки.
- Обычная ссылка «на файл» и на сайт — не сноски, остаются как есть.

## Общие проверки на любой книге набора
- Скорочтение (слово, фраза, подсветка): меток сносок нет; на картинке — пауза с подсказкой «Нажмите, чтобы продолжить».
- Слово перед меткой (`сказал¹,`) читается целиком как «сказал,».
- Старая книга (разобранная до этапа 12) при открытии разбирается заново и остаётся на том же месте (число слов то же).
- Журнал (`adb logcat`) без исключений и без ошибок памяти.

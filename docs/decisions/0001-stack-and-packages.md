# 0001. Стек и пакеты

- Статус: предложено (архитектор, 2026-10-19), ждёт согласия владельца
- Связано: 0002 (модель книги), 0005 (импорт), 0006 (структура)

## Контекст
Flutter 3.47.5 / Dart 3.13.4, Android + iOS. Mac нет: iOS собирается без подписи в GitHub Actions, любой нативный код на iOS проверяется только на iPhone. Значит, главный фильтр для пакета — есть ли в нём нативная часть. Всё хранится на телефоне, сервера нет. Версии проверены на pub.dev 2026-10-19 (справочно, фактические ставит `flutter pub add`).

## Решение
| Задача | Выбор | Нативный код | Почему |
|---|---|---|---|
| Состояние | `flutter_riverpod` 3.4.x (без `riverpod_generator`) | нет | у экрана чтения много связанного состояния (настройки → вёрстка → позиция → RSVP); опыт SmokingAPP |
| База | `drift` 2.35.x + `sqlite3` + `path_provider`; dev: `drift_dev`, `build_runner` | sqlite3, path_provider | опыт обоих проектов, миграции, тесты на in-memory базе |
| Текст книги | свои файлы-кэши на диске (ADR 0002) | нет | книга целиком не нужна в SQL |
| ZIP (EPUB, FB2.ZIP, позже DOCX) | `archive` 4.5.x (loki3d.com, 17,6 млн загрузок) | нет | стандарт де-факто, чистый Dart |
| XML (FB2, EPUB OPF/XHTML) | `xml` 7.1.x (lukas-renggli.ch) | нет | есть потоковый разбор событиями — для FB2 на 5–10 МБ |
| Кодировки TXT/FB2 | **свой код**: таблицы Windows-1251 и KOI8-R (по 128 символов) + определитель | нет | ~150 строк с тестами; `enough_convert` (25 лайков) — запасной |
| Хэш для дублей | `crypto` (dart.dev) | нет | SHA-256 файла |
| Выбор файлов, папок, «Открыть в / Поделиться» | **свой платформенный канал** (Swift + Kotlin, ADR 0005) | да, свой | см. ниже |
| Экран не гаснет | **свой метод в том же канале** (`isIdleTimerDisabled` / `FLAG_KEEP_SCREEN_ON`, ~10 строк) | да, свой | канал всё равно есть; `wakelock_plus` 1.8.x — запасной |
| Тексты | gen-l10n (ARB) + `flutter_localizations` + `intl` | нет | требование CLAUDE.md |
| Шрифты | 2–4 шрифта с кириллицей файлами в `assets/` | нет | `google_fonts` качает из сети — не берём |
| Навигация | встроенный `Navigator` | нет | экранов мало |

Определение кодировки (свой код): BOM → UTF-8/UTF-16; строгий UTF-8 без ошибок → UTF-8; иначе декодируем как 1251 и как KOI8-R и выбираем ту, где больше частых русских букв (о, е, а, и, н, т) в нижнем регистре и меньше «невозможных» сочетаний. Для FB2 сначала смотрим `encoding=` в XML-заголовке.

**«Открыть в / Поделиться» без пакета.** `receive_sharing_intent` 1.9.0 (kasem.dev, проверено) требует на iOS отдельную цель Share Extension в Xcode, App Groups и правку `project.pbxproj` — без Mac это непроверяемо и опасно для бесплатной подписи. Вместо этого iOS-приложение объявляет типы документов в `Info.plist` (EPUB, FB2, FB2.ZIP, TXT); тогда оно появляется в «Поделиться / Открыть в» у Telegram, «Файлов», Safari, почты, а файл приходит в `scene(_:openURLContexts:)`. Код — в уже существующих файлах шаблона (`AppDelegate.swift`, при необходимости `SceneDelegate.swift`), **без новых файлов и целей**. Android: `intent-filter` VIEW/SEND + `MainActivity.kt`.

## Отвергнуто
- `file_picker`: на iOS неизвестный системе тип `.fb2` не всегда выбирается; свой выбор файла (~60 строк Swift) уже проверен в MoneyAPP и использует наши объявленные типы.
- `receive_sharing_intent`, `flutter_sharing_intent`: Share Extension (см. выше).
- `epubx`/`epub_view`/`flutter_html`: давно не обновлялись или дают свою вёрстку, а нам нужна единая модель (ADR 0002) и своя вёрстка (ADR 0003).
- `shared_preferences`: второе хранилище; настройки — таблицей в базе.
- `bloc`, `get_it`, `freezed`, `go_router`: лишнее при нашем размере.

## Последствия
- Чистых Dart-пакетов 5, нативных пакетов 2 (`sqlite3`, `path_provider` — оба проверены в прошлых проектах). Всё остальное нативное — наш код в одном канале, ~250 строк Swift и ~250 Kotlin за весь v1.
- Каждый новый нативный кусок добавляется отдельным шагом: сначала Android (эмулятор), потом iOS (облачная сборка → iPhone).
- Риск: обработка входящего файла при холодном и «тёплом» запуске на iOS — самое хрупкое место; делаем её отдельным этапом (ROADMAP, этап 7) с тестом-сторожем имён канала и ключей `Info.plist`.

# 0003. Вёрстка обычного чтения: настоящие страницы

- Статус: предложено (архитектор, 2026-10-19)
- Связано: 0002 (модель), 0004 (ведущая подсветка)

## Контекст
Владелец хочет «стр. N / M», листание, тап для показа интерфейса, A−/A+, долгое нажатие на слово → скорочтение и подсветку слова после возврата. Номера страниц зависят от шрифта, размера, интервала, полей и экрана. Вёрстку текста во Flutter (`TextPainter`) можно делать только в главном изоляте.

## Решение
**Постраничная вёрстка своим кодом, лениво по главам, с кэшем.**

1. **Разбивка.** Для каждого абзаца главы — `TextPainter` по ширине страницы; по `computeLineMetrics()` набираем строки, пока они помещаются по высоте. Абзац может разорваться между страницами по границе строки. Страница = `[(blockIndex, firstLine, lastLine)]`, плюс первый и последний `wordIndex`.
2. **Рисование.** Страница рисуется `CustomPainter`-ом: для разорванного абзаца рисуется тот же `TextPainter` целого абзаца со сдвигом и обрезкой по строкам. Поэтому переносы строк на странице совпадают с разбивкой точь-в-точь (в том числе при выравнивании по ширине).
3. **Слово под пальцем и подсветка.** `getPositionForOffset` → символ → `wordIndex` (по токенам из ADR 0004). Подсветка слова после скорочтения и ведущая подсветка — `getBoxesForSelection` по `charStart..charEnd` токена.
4. **Лениво и в фоне.** При открытии размечается текущая глава (десятки мс) — книгу сразу можно читать. Остальные главы размечаются порциями между кадрами (≤ 8 мс за кадр). Пока разметка не закончена, внизу «стр. 15 / ≈ 820» (оценка по числу символов), потом точное число.
5. **Кэш.** `layoutKey` = хэш(шрифт, размер, интервал, поля, выравнивание, размер экрана, версия вёрстки). Разбивка сохраняется в `pages-<layoutKey>.bin`; повторное открытие с теми же настройками — мгновенно. Хранить 2–3 последних ключа.
6. **Смена шрифта / поворот.** Запоминаем `wordIndex` первого слова на странице → переразмечаем текущую главу → открываем страницу, где это слово. Номера страниц сохраняются от этого слова, а не по номеру страницы.
7. **Переносы слов.** В v1 по умолчанию выравнивание влево, «по ширине» — опция. Русских переносов во Flutter нет; свой расстановщик (паттерны Лианга + мягкий перенос) — после v1, если выравнивание по ширине будет некрасивым.
8. **Перелистывание** — сдвиг страницы (без «загиба»); свайп влево/вправо тоже листает.

**Тап-зоны (обычное чтение):** левая треть — назад, правая треть — вперёд, середина — показать/скрыть интерфейс. Долгое нажатие на слово — скорочтение с этого слова. Отражение зон для левшей — настройка позже.
**Тап-зоны (скорочтение):** тап в любом месте = пауза + элементы управления; повторный тап по слову = продолжить.

## Отвергнуто
- **Сплошная прокрутка с «виртуальными экранами».** Проще (готовый ленивый список), но «стр. N» скачет при прокрутке, листание тапом неточное (полстроки обрезано), и это не то, чего хочет владелец. Оставляем как возможный режим после v1.
- **Только оценка страниц (символы ÷ символов на страницу).** Дёшево, но «последняя страница» оказывается полупустой или не той; годится лишь как временное число до конца разметки.
- **Разметка всей книги при открытии.** На книге в 500 тыс. слов — несколько секунд ожидания при каждой смене размера шрифта.
- **Вёрстка через WebView (EPUB как HTML).** Тяжело, медленно, плохо синхронизируется с RSVP по словам, плохо проверяется на iOS.

## Последствия
- Своя вёрстка — самый сложный кусок интерфейса (~600–900 строк), но он даёт точные страницы, точное попадание по слову и общую основу для ведущей подсветки.
- Проверки в `flutter test` (тестовый шрифт детерминирован): ни одно слово не теряется и не повторяется между страницами; после смены шрифта открыта страница с тем же словом; картинки и заголовки не разрываются.
- Производительность проверяем на «трудных» больших книгах на телефоне (tester).

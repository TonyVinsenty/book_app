# Правила работы над ReadingAPP

- Перед работой читать `CLAUDE.md` и раздел «Где остановились» в `docs/ROADMAP.md`.
- Любые визуальные изменения приложения самостоятельно проверять на установленном Android-эмуляторе `Pixel_8`: открыть изменённый экран, посмотреть его фактический вид и взаимодействия, исправить найденные проблемы до коммита. Одних макетов и виджет-тестов недостаточно.
- Для проверки на эмуляторе можно использовать `flutter run` с отладочной сборкой. Отдельный APK для установки или передачи пользователю, включая релизный APK, собирать только по его явной просьбе.
- Не запускать iOS build в GitHub Actions и не готовить IPA без явной просьбы пользователя. Запрос отправить исходники на GitHub не означает разрешение на сборку.
- Не запускать сборки по собственной инициативе после push. Владелец сам собирает iOS для проверки на iPhone; APK просит отдельно.
